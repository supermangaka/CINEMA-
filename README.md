# CINEMA+ — онлайн-кинотеатр (портфолио)

Клиентское веб-приложение на HTML/Tailwind CSS/JavaScript (без сборки), использующее
[TMDb API](https://www.themoviedb.org/) для каталога, поиска, жанров и деталей фильмов/сериалов.

## Структура проекта

```
cinema-app/
├── index.html          # разметка страницы
├── css/
│   └── style.css        # glassmorphism, анимации, skeleton loaders, сетки
├── js/
│   ├── config.js         # API-ключ и константы
│   ├── api.js             # обёртка над TMDb API (fetch + try/catch)
│   ├── favorites.js        # избранное через localStorage
│   ├── auth.js               # клиентская авторизация + валидация форм (localStorage)
│   ├── ui.js                     # рендеринг карточек, hero, модалки, toast
│   ├── actors.js                   # карточка актёра: биография + фильмография (TMDb /person)
│   ├── profile.js                    # история просмотров + вкладки профиля
│   └── app.js                          # инициализация, навигация, поиск, фильтры/сортировка, модалки
└── README.md
```

## 1. Получение API-ключа TMDb

1. Зарегистрируйтесь на https://www.themoviedb.org/signup
2. Перейдите в **Settings → API → Create → Developer**
3. Заполните короткую форму (укажите тип использования: "Personal / Education / Portfolio")
4. После одобрения (обычно мгновенно) скопируйте **"API Read Access Token"** (это длинный JWT-токен, начинается не с цифр — именно его нужно использовать, а не "API Key (v3 auth)")
5. Откройте `js/config.js` и вставьте токен:

```js
const CONFIG = {
  TMDB_TOKEN: 'ваш_скопированный_токен',
  ...
};
```

## 2. Запуск проекта

Проект полностью статический (чистый HTML/CSS/JS), поэтому его можно открыть таким способом:

### Локальный сервер

Из-за CORS-политик браузеров лучше не открывать `index.html` напрямую через `file://`,
а поднять простой локальный сервер:

```bash
# Python 3
python3 -m http.server 5500

# или Node.js (npx)
npx serve .

# или VS Code — расширение "Live Server"
```

Затем откройте `http://localhost:5500` в браузере.


## 3. Плеер(Трейлер)

В модальном окне фильма/сериала расположен плеер.

- Вкладка **«Трейлер»** работает «из коробки» — использует официальные YouTube-ссылки
  из ответа TMDb.


Чтобы добавить ещё серверы, допишите объект в массив, который возвращает `getSources()`
в том же файле — переключатель, обработка ошибок загрузки (таймаут 12 сек + плашка
"не удалось загрузить") и остановка видео при закрытии модалки уже реализованы и
подхватят любое количество источников автоматически.

Атрибуты `allow="autoplay; encrypted-media; fullscreen; picture-in-picture"` и
`allowfullscreen` уже стоят на iframe, поэтому выбор качества/озвучки/субтитров и
полноэкранный режим будут работать корректно, если сам провайдер их поддерживает.

## 4. Авторизация и профиль

Реализована полностью клиентская демо-авторизация (`js/auth.js`):

- Регистрация и вход хранятся в `localStorage` (пароли хешируются через
  `crypto.subtle.digest('SHA-256', ...)` — это НЕ криптографически стойкое хранение
  паролей уровня продакшена, для реального проекта нужен backend с bcrypt/argon2 и
  серверными сессиями; здесь это осознанное упрощение для клиентского прототипа).
- После входа кнопка «Войти» в шапке заменяется на аватар — клик открывает модалку
  **«Профиль»** с двумя вкладками:
  - **«Избранное»** — список сохранённых фильмов/сериалов с возможностью удаления.
  - **«История просмотров»** (`js/profile.js`, модуль `History`) — фильм/сериал
    автоматически добавляется сюда при запуске плеера в модальном окне (на любом
    сервере, включая трейлер). История хранится отдельно для каждого аккаунта.

## 5. Сортировка и фильтры

На страницах разделов «Фильмы» / «Сериалы» / «Мультфильмы» доступна панель:

- **Сортировка**: по популярности, по рейтингу, по дате выхода (для сериалов TMDb
  использует поле `first_air_date` вместо `primary_release_date` — это учтено в `api.js`).
- **Жанр** — выпадающий список, загружается динамически из TMDb под выбранный раздел.
- **Год** и **минимальный рейтинг** — дополнительные фильтры.

Все фильтры и сортировка комбинируются и отправляются одним запросом к `/discover`.

## 6. Карточка актёра и фильмография

Актёры в блоке «В ролях» кликабельны (курсор-поинтер, hover-подсветка аватара и
роли). Клик открывает модальное окно `js/actors.js` с данными из TMDb:

- фото, полное имя, дата и место рождения, возраст, сфера деятельности;
- биография (`/person/{id}`);
- карусель фильмографии (`/person/{id}/combined_credits`), отсортированная по
  популярности — клик по любой карточке в ней закрывает карточку актёра и
  открывает выбранный фильм/сериал.

## 7. Валидация форм авторизации

`js/auth.js` содержит переиспользуемые функции валидации (`validateLogin`,
`validateRegister`, `isValidEmail`, `isValidPassword`), которые `app.js`
использует для показа ошибок **под конкретными полями** (без `alert()`):

- проверка формата email регулярным выражением;
- пароль не короче 6 символов (`Auth.MIN_PASSWORD_LENGTH`);
- обязательное совпадение пароля и его подтверждения при регистрации;
- поле подсвечивается красным (`.auth-input.invalid`), ошибка сбрасывается,
  как только пользователь начинает вносить исправления.

При регистрации также генерируется детерминированный цвет аватара на основе
email (`generateAvatarColor`), который сохраняется в сессии вместе с именем —
после входа кнопка «Войти» в шапке заменяется на цветной аватар с инициалом.

## 8. Функционал

- **Главная**: hero-баннер случайного трендового тайтла, ряды «В тренде», «Популярные фильмы/сериалы», «Новинки», «Топ рейтинга», «Мультфильмы» (горизонтальные слайдеры со скроллом)
- **Разделы**: Фильмы / Сериалы / Мультфильмы с сортировкой и фильтрами по жанру, году и минимальному рейтингу; жанры и год динамически обновляются под категорию, для «Мультфильмов» жанр Animation исключён из списка (применяется автоматически)
- **Поиск**: живой поиск с debounce (450мс), мультипоиск по фильмам и сериалам
- **Модальное окно фильма**: постер, описание, жанры, кликабельный актёрский состав, мульти-серверный плеер с переключателем и обработкой ошибок загрузки
- **Модальное окно актёра**: биография, дата/место рождения, фильмография с переходом к фильмам
- **Избранное**: сохраняется в `localStorage`, отдельный раздел в навигации и вкладка в профиле
- **Авторизация и профиль**: вход/регистрация с валидацией полей, персональный цвет аватара, история просмотров, привязанная к аккаунту
- **UX**: glassmorphism-шапка с блюром, skeleton loaders на время загрузки, hover/active-микроанимации на всех интерактивных элементах, полностью адаптивная сетка (2 колонки на мобильном → 6 на широких экранах)
